# Lista de preparación para AdSense

Esta lista no garantiza aprobación. Sirve para evitar errores frecuentes antes de enviar el sitio a revisión.

## Contenido

- [ ] Revisar todas las páginas y eliminar texto provisional.
- [ ] Publicar más lecciones y guías originales de calidad de forma progresiva.
- [ ] Mostrar autor o responsable editorial real cuando corresponda.
- [ ] Mantener fecha de revisión y fuentes primarias.
- [ ] No copiar materiales de academias, libros, exámenes o páginas oficiales.
- [ ] No generar páginas masivas con poco valor.

## Confianza

- [ ] Configurar un correo de contacto real.
- [ ] Revisar privacidad, términos, metodología, correcciones y política publicitaria.
- [ ] Confirmar que el dominio utiliza HTTPS.
- [ ] Probar todos los enlaces oficiales.
- [ ] Explicar claramente que RutaBeca es independiente.

## Experiencia

- [ ] Probar navegación en celular y computadora.
- [ ] Comprobar que no existan páginas vacías, errores o botones sin función.
- [ ] Evitar ventanas emergentes antes del contenido.
- [ ] Mantener más contenido que publicidad.
- [ ] No colocar anuncios durante simulacros, formularios o pantallas de carga.

## Publicación

- [ ] Añadir el dominio a Search Console.
- [ ] Enviar `/sitemap.xml`.
- [ ] Confirmar que `/robots.txt` permite rastreo.
- [ ] Crear `ads.txt` exactamente con la línea entregada por AdSense.
- [ ] Configurar una solución de consentimiento certificada cuando corresponda.
- [ ] Activar los identificadores publicitarios únicamente después de recibirlos.

Fuentes principales:

- Políticas para Editores de Google: https://support.google.com/adsense/answer/10502938?hl=es
- Políticas de spam de Google Search: https://developers.google.com/search/docs/essentials/spam-policies?hl=es
- Ayuda oficial de AdSense: https://support.google.com/adsense/
